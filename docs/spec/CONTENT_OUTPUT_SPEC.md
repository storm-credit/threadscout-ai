# Content Output Specification v1

Status: DESIGN ONLY.

Every evidence-ready candidate produces four distinct reader-value angles: practical result, mechanism/demo, comparison/decision, and limitation/best-fit. They must differ in argument, not just wording.

Each draft carries an angle ID, hook, body, caution where needed, CTA, commercial-disclosure state, claim references, and proposed media treatment.

Research-based copy uses research wording. First-hand wording requires a usage record. Unknown current facts are omitted or qualified. Writer stops when the brief conflicts with evidence or when the requested wording exceeds the verified state.
