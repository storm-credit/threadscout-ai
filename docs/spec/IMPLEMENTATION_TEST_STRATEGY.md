# Future Implementation Test Strategy v1

Status: DESIGN ONLY.

Later implementation verification uses domain invariant tests, handoff contract tests, deterministic scenario replays, mobile workflow tests, source-adapter contract tests, stale/preflight scenarios, configuration/security checks, and regression fixtures.

Required fixture families include normal practical products, exact user-supplied products, high-score unresolved candidates, issue-trigger exact/alternative cases, research media without final-use status, stale current facts, duplicates, suppressed candidates, and no-good-candidate days.

A future slice is complete only when both its normal path and its relevant blocked/failure states satisfy the mapped design acceptance criteria.
