# Product Owner Decision Register v1

Status: DESIGN ONLY.

## Direction already represented in the baseline

- Korean, mobile-first, single-user MVP
- practical demonstrable products as the primary lane
- exactly six agents including Orchestrator
- no dedicated price agent
- approval-first workflow
- Opportunity Inbox as the primary mobile screen
- four differentiated strategy/draft paths
- opportunity score separated from evidence/risk/freshness
- public-event/celebrity signals only as product-relevant triggers
- research media separated from final-use media
- exact and alternative products clearly separated
- no forced daily posting quota

## Provisional values awaiting promotion

- 0–3 daily posting capacity
- normally no more than one affiliate-heavy post per day
- five recommendations on the first screen
- initial simulation score floor
- freshness windows
- retention periods
- suppression restore behavior

## Live-dependent decisions

- actual platform capabilities for the target account
- exact listing evidence source
- first commercial/affiliate program rules
- deployment environment
- credential-storage environment
- source-specific media-use rules
- actual available performance metrics

## Review rule

A value is marked `approved` only when the product owner explicitly accepts it or when the decision is based on verified live-environment evidence and the owner accepts the resulting configuration. Silence or continued design work does not automatically promote a provisional value.
