## D. Opportunity Inbox — selected

```text

Source status / Publish status
Raw 20 · Recommended 5 · Verify 2

#1 Candidate A             88
Why now: rising interest
Reader value: clear problem solved
Evidence: PARTIAL   Risk: LOW
Product: LIKELY     Media: REVIEW
Main blocker: exact variant
[Verify evidence] [Hold]

#2 Candidate B             86
Evidence: READY     Risk: LOW
[Create 4 strategies]

Today | Verify | Draft | Schedule | Results
```

## Selected hierarchy

1. rank + candidate name + opportunity score
2. why-now
3. reader value
4. evidence readiness + risk
5. product/media state
6. one dominant blocker
7. one primary CTA and one secondary hold action

At 360 px the target is one complete card plus the start of the second card. No critical state is conveyed by color alone.
