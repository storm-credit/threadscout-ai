# Design Document Taxonomy v1

Status: DESIGN ONLY.

Level A core authority: Master Spec, Product Requirements, MVP Scope, System Architecture, User Flows/UI, Agent Contracts/Handoffs, Data Model, Source Strategy, Safety, Design Freeze.

Level B domain detail: ranking, evidence, media, issue routing, product matching, content, review, commercial mapping, operations, scheduling, analytics, security, retention, prompt/routing/state details.

Level C review/support: worked examples, wireframes, edge cases, decision registers, acceptance tests, traceability, contradiction review, CI semantics, gap analysis, and finalization plan.

Before baseline promotion, duplicate authority should be consolidated rather than creating parallel normative rules. Level C may test or explain a rule but does not override Level A/B.
