# Issue-to-Product Decision Table v1

Status: DESIGN ONLY.

Issue-triggered candidates use separate grades for source reliability, product relationship, product match, media permission, commercial mapping, and freshness. No single grade can replace the others.

Allowed outcomes are: verify further, create non-commercial information content, create exact-product content, present an explicitly labeled alternative, hold, or block.

A stronger statement is never allowed than the evidence supports. A substitute cannot be presented as the same product. Media permission is evaluated separately from issue evidence. Stale or corrected evidence invalidates dependent drafts.
