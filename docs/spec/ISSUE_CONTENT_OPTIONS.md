# Celebrity / Broadcast / Issue Content — Four Options

## Decision question

How much should ThreadScout use celebrity, entertainer, broadcast, sports, and cultural issues to discover product opportunities?

| Option | Description | Benefit | Main risk | Decision |
|---|---|---|---|---|
| A. No issue signals | Product-only discovery; ignore public figures/events | simplest and safest | misses strong real-world product demand signals | not selected |
| B. Official endorsement only | Allow only official collaborations/ads | very high certainty | too narrow; misses organic public-use moments | not selected |
| C. Public product-relevant issue trigger | Detect public events plus purchase/product questions; verify relationship and exact product separately | captures useful trends while preserving trust | more verification/rights complexity | **selected** |
| D. Broad celebrity/trend feed | Follow names and viral issues first, then look for monetization | high volume/attention | gossip drift, rumor/privacy/defamation and weak product fit | rejected |

## Selected Option C

The system may use a public figure/event only as a **trigger** when:

- the context is public and sourceable
- there is a product/object connection
- purchase-intent or reader-value signal exists
- the exact relationship is classified by Verifier
- private-life/rumor content is excluded
- media rights and exact affiliate mapping are separately checked

## Why C

It captures moments like “방송에서 보여서 사람들이 제품 정보를 묻는 상황” without letting the account become a celebrity-news account.

## Stop rule

If the candidate's value disappears when the person's fame is removed and there is no useful product decision for the reader, reject the affiliate angle.
