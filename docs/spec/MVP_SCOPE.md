# MVP Scope v1

Status: DESIGN ONLY.

## Must have

- single-user Korean mobile-first Opportunity Inbox
- fixed six-agent orchestra
- candidate ranking separated from evidence/risk/freshness
- exact/likely/substitute/unresolved product state
- evidence workbench and source lineage
- media research/final-use separation
- issue-trigger grading and decision routing
- four strategies and four mapped drafts
- Guardian review and bound human review state
- suppression controls
- local schedule state and preflight model
- auditability and stale-evidence invalidation

## May remain disabled at first

- live Threads discovery
- live commercial destination mapping
- live scheduling/publishing
- conversion/revenue attribution

These may be deferred only when the UI clearly shows them as disabled and the affected workflow has a safe fallback.

## Not MVP

- multi-account SaaS
- automatic comments/likes/follows
- automatic purchases/payments
- learned ranking replacing deterministic weights
- generated final-use media
- commercial trend-provider dependence
- cross-platform publishing
- advanced experiment orchestration

## MVP completion principle

The MVP is complete when one user can move a candidate from discovery or manual input through evidence, four strategies, four drafts, Guardian review, human review, and a safe local schedule state without any hidden truth or media-rights bypass.
