# Evidence Thresholds v1

Status: DESIGN ONLY.

Different claims require different evidence. Discovery wording may proceed with a traceable observation. Exact-product wording requires an exact match. Current price or stock requires a timestamped fresh source. Personal-use wording requires a user-confirmed usage record. Public-event relationship wording cannot exceed the verified relation grade. Final-use media requires an allowed final-use state. An affiliate destination may be presented as the same item only when exact mapping is verified.

When evidence is below threshold, the system narrows or removes the claim, labels an alternative clearly, requests more evidence, or holds the candidate. Unknown values are valid states and must not be filled from model memory.
