# Photo / Video Strategy — Four Options

## Decision question

How should ThreadScout find and use photos/videos while protecting rights and product accuracy?

| Option | Description | Benefit | Main risk | Decision |
|---|---|---|---|---|
| A. User-owned media only | Never reference external media | lowest rights risk | weak discovery and difficult product matching | not selected |
| B. Licensed/publication-ready sources only | Search only assets with clear reuse permission | simpler publishing | misses useful analysis evidence | not selected |
| C. Separate analysis evidence from publication rights | May discover/reference external media internally, but publication requires explicit action-specific rights; prefer owned/licensed assets | strongest balance of discovery and safety | requires rights metadata and replacement workflow | **selected** |
| D. Public means reusable | Download/repost public social/media assets unless challenged | fast, visually rich | unacceptable copyright, platform, trust, and endorsement risk | rejected |

## Selected Option C

Every media asset has two independent questions:

1. May the system analyze/reference it internally?
2. May the user publish/re-upload/embed/transform it in this specific way?

Publication defaults to no until the intended action is allowed.

## Preferred publication order

1. user-owned exact-product media
2. explicitly licensed media
3. permitted platform-native embed/link
4. no media

AI-generated media is a later optional capability and may not fabricate a real public figure using or endorsing a product.
