# Edge Cases v1

Status: DESIGN ONLY.

High opportunity with weak evidence stays in verification. Exact product without a trustworthy commercial destination can still become non-commercial content. Duplicate discoveries merge into one candidate while keeping source lineage. A stale issue may be reframed as evergreen only when product value stands independently.

A useful media reference with unresolved final-use state is replaced or omitted. A visual clue that conflicts with model evidence never becomes exact.

If four strategies collapse into paraphrases, Strategist retries once. If fewer than five candidates are viable, show fewer. If none are viable, `오늘 추천 없음` is valid. Suppression and evidence gates always win over ranking.
