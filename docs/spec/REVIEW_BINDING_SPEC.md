# Review Binding Specification v1

Status: DESIGN ONLY.

A review decision references one specific draft revision plus the evidence, media state, destination mapping, and disclosure state used by that draft.

When any material referenced item changes, the review state becomes stale and must be revisited before the item can advance.

The final review surface shows the selected content, referenced evidence version, media treatment, destination mapping, and remaining warnings. Saving an edit does not silently preserve an earlier review decision.
